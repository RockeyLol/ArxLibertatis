This is a fork of ArxLibertatis aimed at changing the UI to match the Xbox version. I've already implemented a one-button easy magic mode, because doing it with a gamepad is very difficult.

Easy magic menu:
F7 open menu
[  ] chose magic
V use magic

Fast user item menu
F8 open menu
[ ] chose item
E use item
G pick up item for use on npc or objects
